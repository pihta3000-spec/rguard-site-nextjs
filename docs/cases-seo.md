# SEO кейсов

В редакторе кейса появился блок SEO: `metaTitle`, `metaDescription`, `ogImage`.
Название, краткий текст карточки, slug и существующие идентификаторы не меняются.
Если SEO-поле пустое, сайт использует прежнее значение: название/краткое описание.

Для обычного импорта XLSX в лист КЕЙСЫ можно добавить необязательные колонки
`SEO Title` и `SEO Description` (также поддерживаются `metaTitle` и `metaDescription`).
Порядок колонок не важен. Сопоставление по прежней колонке Slug.
Отсутствующие колонки и пустые SEO-ячейки сохраняют существующие значения.
Заполнение только одного SEO-поля не стирает другое. Очистить поле можно в админке.

Разовый скрипт `scripts/apply-cases-seo-20261023.mjs` заполняет только пустые SEO-поля
26 существующих кейсов и сохраняет маркер в `content_migrations`.
Повторный деплой не перезаписывает ручные изменения. Контент и медиа не изменяются.
Устаревший CLI `reimport-cases.mjs` выполняет полное удаление и пересоздание кейсов;
он не является обычным импортом админки и не должен использоваться для обновлений.
