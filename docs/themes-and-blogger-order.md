# Темы и порядок блогеров — 2026-09-22

Пока локально, без деплоя.

- Кнопка солнце/луна в шапке, доступна на мобильном и десктопе.
- По умолчанию тёмная тема. Выбор хранится в localStorage `rguard-theme`.
  Скрипт в head применяет сохранённую тему до отрисовки. При запрете storage
  переключение работает в текущем документе; перезагрузка возвращает тёмную тему.
- Админка остаётся тёмной, пользовательская настройка публичного сайта сохраняется.
- Общие поверхности переведены на CSS-переменные. Фотографии и видео не инвертируются.
  Белые логотипы и медиаконтролы остаются на тёмной подложке (`media-dark`).
- Анимации сохраняют исходную яркость в обеих темах, без дополнительного приглушения.
- На узком экране кнопки финального шага брифа переносятся без горизонтального скролла.
- `apply-blogger-order-20260922.mjs` меняет только order с backup базы: Денис №4,
  Семён №5, остальные сохраняют относительный порядок; первые три не меняются.
  Скрипт включён после старых seed-скриптов в будущий деплой.

Проверки: production build; 3 node tests (авторство, темы, сортировка).
В браузере: главная, блогеры, кейсы, мероприятия, контакты, профиль эксперта,
статьи, бриф; переключение темы и reload, мобильное меню, финальный шаг брифа
с выключенным согласием. Ширины 1280, 390 и 320; проверенные формы без overflow.
Ошибок в консоли браузера не обнаружено. Реальные заявки не отправлялись.
